# P00-T21 Frame Guard + Error Overlay + Crashlytics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An exception inside a frame never freezes Gravity Flow for good, and every report Crashlytics receives is actionable (JS stack, custom keys, breadcrumbs, deduplicated, capped per session).

**Architecture:** A guard in `src/platform/frameGuard.ts` replaces `game.step` from the Phaser `READY` event, catches every frame error, logs and reports it, and after `FRAME_ERROR_BURST` errors within `FRAME_ERROR_WINDOW_MS` puts the loop to sleep behind a plain-DOM "Tap to restart" overlay (`src/platform/errorOverlay.ts`). `src/services/Crash.ts` gains parsed V8 stacks (`src/services/stackParse.ts`), dedupe plus the per-session cap, custom keys (`src/services/crashContext.ts`) and a working breadcrumb call. The boot-smoke harness gains `ctx.expectSignal(matcher)` so a dev-only check can provoke the error on purpose (`window.__crashTest`), and `debug-handles` proves the hook is absent from `dist/`.

**Tech Stack:** Phaser 3.90.0 (bundled Matter), TypeScript strict, Vite 5, Vitest 1.6 (`environment: 'node'`, no DOM), Capacitor 8.5.2 with `@capacitor-firebase/crashlytics` 8.5.2, Node Playwright 1.63.0 harness (`scripts/harness/`).

## Design decisions (one line each)

1. **Burst policy, not "N consecutive":** `frameGuardDecision` returns `overlay` at 3 errors inside 2000 ms (phase doc Step 5). A persistent error hits that in about 3 frames (~50 ms), while isolated transient errors (each costs one frame) never add up.
2. **Injected reporting:** `installFrameGuard(game, { report, showOverlay })` gets `Crash.recordError` and the overlay from `main.ts`, so `src/platform` gains no services import and the guard is testable in node with a fake game.
3. **The guard always `console.error`s what it catches:** on the production web build `Crash` is silent, so without this the bundle smoke would stop seeing frame errors once they no longer escape. On Android it reaches logcat.
4. **Dedupe key = the message itself:** the set of sent messages never holds more than `CRASH_MAX_PER_SESSION` (5) entries, so no hash is needed (no collisions) and the set doubles as the counter.
5. **`build` key = `version+androidBuild` (e.g. `1.0.0+1`):** these are the two inputs of the versionCode (D-20), so `scripts/lib/versionCode.mjs` keeps the one formula. Crashlytics records the versionCode itself on every report.
6. **Breadcrumb fix:** the seam called `addLogMessage`, which the Android plugin does not have (its `@PluginMethod` is `log`), so no breadcrumb ever reached Crashlytics. P00-T21 needs breadcrumbs, so it fixes the name and pins it against the plugin's Java source.
7. **Lifecycle fold-in uses `try/finally`, not "report first":** the P00-T19 fix passes tuned the order (lifecycle step, then activity report). `finally` keeps that order and the error still propagates to the global bridge. `notifyForeground()` moves into a `finally` too: same failure mode, one line.
8. **`dist/` proof extends `debug-handles`:** its preview run already asserts "no `window.__*` handle" at runtime. It now also scans every JS file under `dist/` for the DEV handle names, in the style of `web-store-copy`'s bundle scan. Its dev run is the positive control.
9. **`errorOverlay.ts` has no Vitest test:** Vitest runs in node with no DOM and no new deps are allowed. The dev-leg check `crash-overlay` exercises it in real Chromium (text, role, on top, tap reloads).
10. **The overlay silences audio** (`sharedAudio().suspend()` in `main.ts`): a stopped game must not keep playing its music.

```js
// What counts as a failure signal on a page, and the log that collects them. Pure: unit-tested in signals.test.mjs.
//
// The rule is "zero exclusions": any console.error, any uncaught exception or unhandled rejection (both arrive as a
// Playwright `pageerror`), and any failed or 4xx/5xx SAME-ORIGIN request fails the run. There is no allow-list here.
// Something noisy gets fixed at its source (the favicon 404 was fixed with a <link rel="icon"> in index.html).
// Third-party requests are the one scoping rule: the harness only owns what the app itself serves.
//
// Expected signals (P00-T21) are not an allow-list. A check that provokes an error ON PURPOSE (window.__crashTest throws inside
// update) declares it with ctx.expectSignal(matcher, label) right before the action. From then on, a signal matching that specific
// matcher is claimed instead of failing the job, and the job FAILS if none arrives. A matcher must name the error (compileMatcher
// refuses a catch-all), and it only ever applies to the one job that declared it.

export function isSameOrigin(url, origin) {
  try {
    return new URL(url).origin === origin;
  } catch {
    return false;
  }
}

const where = (loc) => (loc && loc.url ? `${loc.url}${loc.lineNumber !== undefined ? `:${loc.lineNumber}` : ''}` : '');

/** @param {{type: string, text: string, location?: {url?: string, lineNumber?: number}}} msg */
export function classifyConsoleMessage(msg) {
  if (msg.type !== 'error') return null;
  return { kind: 'console.error', text: msg.text, where: where(msg.location) };
}

/** An uncaught exception or an unhandled promise rejection (Chromium reports both through Runtime.exceptionThrown). */
export function classifyPageError(err) {
  const isError = err !== null && typeof err === 'object' && 'message' in err;
  const text = isError ? `${err.name ?? 'Error'}: ${err.message}` : String(err);
  const frame = isError && typeof err.stack === 'string' ? (err.stack.split('\n').find((l) => l.trim().startsWith('at ')) ?? '') : '';
  return { kind: 'pageerror', text, where: frame.trim() };
}

/** @param {{url: string, failure: string}} req */
export function classifyRequestFailed(req, origin) {
  if (!isSameOrigin(req.url, origin)) return null;
  return { kind: 'request failed', text: req.failure, where: req.url };
}

/** @param {{url: string, status: number}} res */
export function classifyResponse(res, origin) {
  if (res.status < 400 || !isSameOrigin(res.url, origin)) return null;
  return { kind: `http ${res.status}`, text: `HTTP ${res.status}`, where: res.url };
}

const ASSET_TYPES = new Set(['image', 'script', 'stylesheet', 'font', 'media']);
const DATA_TYPES = new Set(['fetch', 'xhr']);

/**
 * `vite preview` (like most SPA hosts) answers a request for a file that does not exist with index.html and status 200,
 * so a missing asset never shows up as a 404. An asset request that comes back as HTML is exactly that: flag it.
 * @param {{url: string, status: number, resourceType: string, contentType?: string}} res
 */
export function classifySpaFallback(res, origin) {
  if (res.status >= 400 || !isSameOrigin(res.url, origin)) return null;
  if (!res.contentType || !res.contentType.toLowerCase().includes('text/html')) return null;
  const isAsset = ASSET_TYPES.has(res.resourceType);
  let isDataFile = false;
  if (DATA_TYPES.has(res.resourceType)) {
    const ext = /\.([a-z0-9]+)$/i.exec(new URL(res.url).pathname)?.[1]?.toLowerCase();
    isDataFile = ext !== undefined && ext !== 'html' && ext !== 'htm';
  }
  if (!isAsset && !isDataFile) return null;
  return { kind: 'missing file', text: `a ${res.resourceType} request got text/html (the SPA fallback, so the file does not exist)`, where: res.url };
}

/**
 * Compile a ctx.expectSignal matcher: { kind?, text }. `text` is required. A non-empty string matches as a substring of the signal
 * text; a RegExp is searched (String.prototype.search, so a /g flag is harmless). There is no catch-all: a blank string or a RegExp
 * that matches the empty string is refused, so an expectation can only claim the specific error a check provokes on purpose.
 * `kind` (optional) must equal the signal's kind exactly ('console.error', 'pageerror', 'request failed', 'http 404', ...).
 */
export function compileMatcher(matcher) {
  const { kind, text } = matcher !== null && typeof matcher === 'object' ? matcher : {};
  if (kind !== undefined && (typeof kind !== 'string' || kind.trim() === '')) {
    throw new Error('expectSignal: kind, when given, must be a non-empty string such as "console.error" or "pageerror"');
  }
  let test;
  let what;
  if (typeof text === 'string' && text.trim() !== '') {
    test = (s) => s.includes(text);
    what = `containing ${JSON.stringify(text)}`;
  } else if (text instanceof RegExp && ''.search(text) === -1) {
    test = (s) => s.search(text) !== -1;
    what = `matching ${String(text)}`;
  } else {
    throw new Error('expectSignal: text must be a non-empty string or a RegExp that cannot match the empty string (no catch-all)');
  }
  return {
    describe: `a ${kind ? `${kind} ` : ''}signal ${what}`,
    matches: (signal) => (kind === undefined || signal.kind === kind) && test(String(signal.text)),
  };
}

export function createSignalLog() {
  const list = [];
  const claimed = [];
  const expectations = [];
  let closed = false;
  return {
    /** Record a signal. One that an expectation matches is claimed (counted there, never a failure); a closed log records nothing. */
    add(signal) {
      if (!signal || closed) return;
      const owner = expectations.find((e) => e.matcher.matches(signal));
      if (owner) {
        owner.matched.push(signal);
        claimed.push(signal);
        return;
      }
      list.push(signal);
    },
    /** ctx.expectSignal: claim the signals matching `matcher` from now on. Returns { count(), signals() }. */
    expect(matcher, label) {
      const compiled = compileMatcher(matcher);
      const entry = { label: label || compiled.describe, matcher: compiled, matched: [] };
      expectations.push(entry);
      return { count: () => entry.matched.length, signals: () => entry.matched.slice() };
    },
    /** Every expectation with its match count; the runner fails the job for each one still at 0. */
    expectations: () => expectations.map((e) => ({ label: e.label, describe: e.matcher.describe, count: e.matched.length })),
    claimed: () => claimed.slice(),
    mark: () => list.length,
    since: (mark) => list.slice(mark),
    all: () => list.slice(),
    size: () => list.length,
    /** Teardown aborts in-flight requests; those are not the app's fault, so a closed log records nothing. */
    close() {
      closed = true;
    },
  };
}
```

```js
// Runs one job (one check at one viewport) in its own browser context, so no job sees another's state.
//
// A job: open a page with the failure-signal listeners, boot the app to the main menu (unless the check boots itself),
// run the check, then close the context. Page failure signals (console.error, pageerror / unhandled rejection, failed
// same-origin request) are collected for the whole job and fail it even if every assertion passed. The one exception is a
// signal the check declared with ctx.expectSignal for an error it provokes on purpose (lib/signals.mjs).

import { mkdirSync } from 'node:fs';
import path from 'node:path';
import { openPage } from './browser.mjs';
import { bootToMenu, frames } from './game.mjs';
import { createRecorder } from './report.mjs';

export async function runJob({ browser, job, mode, origin, artifactsDir = null }) {
  const { check, viewport } = job;
  const started = Date.now();
  const rec = createRecorder();
  const { context, page, signals } = await openPage(browser, { viewport, origin, seed: check.seed });
  const extras = [];

  const ctx = {
    mode,
    origin,
    viewport,
    signals,
    expect: rec.expect,
    /** Count something under a label; the totals are shown in the NOTES column of the result table. */
    tally: rec.tally,
    /** Record a list of { ok, label, detail } assertions. */
    record(assertions) {
      for (const a of assertions) rec.expect(a.ok, a.label, a.detail);
    },
    /**
     * Declare a failure signal this check provokes ON PURPOSE (P00-T21: the frame errors window.__crashTest injects). From this call
     * until the job ends, a signal matching `matcher` ({ kind?, text }, see compileMatcher in lib/signals.mjs) is claimed: it does
     * not fail the job. If none matched by the end of the job, the job fails. Returns { count(), signals() } to wait on or count.
     * Declare it right before the action that provokes the error, never at the top of a check "just in case".
     */
    expectSignal: (matcher, label) => signals.expect(matcher, label),
    /** A second, fresh page of this job (own context and seed), booted to the main menu. Closed with the job. */
    async openPage({ seed = {} } = {}) {
      const extra = await openPage(browser, { viewport, origin, seed, signals });
      extras.push(extra);
      await extra.page.goto(`${origin}/`, { waitUntil: 'load' });
      await bootToMenu(extra.page);
      return extra.page;
    },
    /** Run fn as one named assertion that fails on a throw or on any page error raised while it ran. */
    async step(label, fn) {
      const mark = signals.mark();
      try {
        await fn();
      } catch (err) {
        rec.fail(label, err);
        return false;
      }
      const raised = signals.since(mark);
      return rec.expect(raised.length === 0, label, raised.map((s) => `${s.kind}: ${s.text}`).join(' | '));
    },
  };

  try {
    await page.goto(`${origin}/`, { waitUntil: 'load' });
    if (check.boot !== 'none') await bootToMenu(page, { skipSplashes: check.boot !== 'natural' });
    await check.run(page, ctx);
    await frames(page, 4).catch(() => undefined); // let a trailing async error surface before the listeners close
  } catch (err) {
    rec.fail('the check did not complete', err);
  } finally {
    signals.close();
    // An expectation that never matched fails the job: the provoked error did not happen, so what it was meant to prove is unproven.
    for (const e of signals.expectations()) rec.expect(e.count > 0, `expected signal arrived: ${e.label}`, `nothing matched: ${e.describe}`);
    rec.tally('expected signals', signals.claimed().length);
    if (artifactsDir && (rec.failures().length > 0 || signals.size() > 0 || rec.total() === 0)) {
      // What the page looked like when the job failed. Best effort: a dead page has nothing to show.
      try {
        mkdirSync(artifactsDir, { recursive: true });
        await page.screenshot({ path: path.join(artifactsDir, `${check.name}-${viewport.label}-${mode}.png`) });
      } catch {
        // no screenshot
      }
    }
    for (const extra of extras) await extra.context.close().catch(() => undefined);
    await context.close().catch(() => undefined);
  }

  const list = signals.all();
  const failures = rec.failures();
  const empty = rec.total() === 0;
  return {
    check: check.name,
    viewport: viewport.label,
    mode,
    status: failures.length === 0 && list.length === 0 && !empty ? 'PASS' : 'FAIL',
    passed: rec.passed(),
    total: rec.total(),
    signals: list,
    failures,
    assertions: rec.all(),
    tallies: rec.tallies(),
    ms: Date.now() - started,
  };
}
```

```ts
// V8 stack traces -> the frames Crashlytics shows and groups non-fatals by (P00-T21). The Android System WebView is Chromium, so V8's
// format is the only one parsed:
//     at functionName (https://localhost/assets/index-abc.js:1:2345)
//     at new ClassName (url:line:col)  ·  at async fn (url:line:col)  ·  at url:line:col  (no function name)
// Lines without a position (the "Error: message" header, `at Array.forEach (<anonymous>)`, native frames) are skipped. A location
// that is a URL is reduced to its path (`assets/index-abc.js`, `src/scenes/GameScene.ts`): the origin and the dev server's ?t= stamp
// carry nothing and would split one crash into many issues. The shape is @capacitor-firebase/crashlytics's StackFrame
// (functionName, fileName, lineNumber). The plugin has no column field, so the column is dropped.
import { PLATFORM } from '../config/platform.config';

export interface StackFrame {
  functionName: string;
  fileName: string;
  lineNumber: number;
}

export const ANONYMOUS_FUNCTION = '(anonymous)';

const NAMED = /^\s*at\s+(?:async\s+)?(.+?)\s+\((.+):(\d+):(\d+)\)\s*$/;
const UNNAMED = /^\s*at\s+(?:async\s+)?(.+):(\d+):(\d+)\s*$/;
const URL_PROTOCOLS = new Set(['http:', 'https:', 'capacitor:', 'file:']);

function shortFile(location: string): string {
  try {
    const url = new URL(location);
    if (URL_PROTOCOLS.has(url.protocol)) return url.pathname.replace(/^\/+/, '') || location;
  } catch {
    // not a URL (an eval frame, a bare path): keep it as it is
  }
  return location;
}

/** The frames of a V8 `error.stack`, in V8's order (the throwing frame first), at most PLATFORM.CRASH_MAX_STACK_FRAMES. */
export function parseStack(stack: string | null | undefined): StackFrame[] {
  if (!stack) return [];
  const frames: StackFrame[] = [];
  for (const line of stack.split('\n')) {
    if (frames.length >= PLATFORM.CRASH_MAX_STACK_FRAMES) break;
    const named = NAMED.exec(line);
    if (named) {
      frames.push({ functionName: named[1], fileName: shortFile(named[2]), lineNumber: Number(named[3]) });
      continue;
    }
    const unnamed = UNNAMED.exec(line);
    if (unnamed) frames.push({ functionName: ANONYMOUS_FUNCTION, fileName: shortFile(unnamed[1]), lineNumber: Number(unnamed[2]) });
  }
  return frames;
}
```

```ts
// Firebase Crashlytics, dynamically imported and guarded by Capacitor.isNativePlatform().
// init() also installs a global error bridge so uncaught errors/rejections are
// recorded (and visible in web dev). Thin seam, mirrors Ads/IAP/Analytics.
//
// IMPORTANT: a Capacitor registerPlugin() proxy is *thenable* (proxy.then is a
// callable that forwards to a native "then" method). So we must NEVER let the proxy
// become a promise resolution value (return it from an async fn / await it /
// Promise.resolve it) — that would invoke proxy.then -> "not implemented on android".
// `ensure()` therefore resolves to a boolean; callers use the module-scoped `plugin`.
//
// Collection switch (D-10.5). The manifest sets firebase_crashlytics_collection_enabled=false, which is the default of a FRESH
// install only: setCrashlyticsCollectionEnabled() is persisted by Crashlytics (DataCollectionArbiter, SharedPreferences) and takes
// precedence over the manifest, so once enable() has run, collection is already on at process start from the next launch, before
// UMP has answered. Loading the plugin (init, log, recordError, setKeys) never changes collection. enable() / disable() are the only
// switches; bootServices calls enable() once consent has resolved, whatever the outcome, and disable() only when
// CRASH_REQUIRES_ANALYTICS_CONSENT is on and analytics_storage is denied (the legal check on that default is a STATUS gate).
//
// Reports (P00-T21). recordError sends the message with its parsed V8 stack (stackParse.ts), so Crashlytics shows and groups the
// JavaScript frames instead of the plugin's own Java frames. Each distinct message is sent once per session, and at most
// PLATFORM.CRASH_MAX_PER_SESSION reports are sent per session, so an error that repeats every frame cannot flood the bridge or the
// quota. The set of sent messages is also the counter and never holds more than the cap, so the message itself is the dedupe key.
// setKeys sets Crashlytics custom keys (main.ts: scene, level, mode, webview_ver, renderer, build) and sends only values that
// changed. log() leaves a breadcrumb on the next report through the plugin's `log` method.
import { Capacitor } from '@capacitor/core';
import { PLATFORM } from '../config/platform.config';
import { parseStack, type StackFrame } from './stackParse';

type KeyType = 'string' | 'long' | 'double';

type Crashlytics = {
  setEnabled(o: { enabled: boolean }): Promise<void>;
  log(o: { message: string }): Promise<void>;
  setCustomKey(o: { key: string; value: string | number; type: KeyType }): Promise<void>;
  recordException(o: { message: string; stacktrace?: StackFrame[] }): Promise<void>;
};

let plugin: Crashlytics | null = null;
let ready: Promise<boolean> | null = null;
// The last collection state asked for in this session (null = nothing asked yet). A repeat of the same state is not sent again.
let collection: boolean | null = null;
// The messages reported this session (never more than CRASH_MAX_PER_SESSION).
const reported = new Set<string>();
// The last value sent for each custom key; a repeat is not sent again.
const sentKeys = new Map<string, string | number>();

// Resolves true once the native plugin is available. Does NOT return the proxy.
// The in-flight promise is memoized, so every caller (init, log, recordError, setKeys, enable) waits on the same load instead of
// seeing a half-initialised `plugin === null` and dropping its report. A failed load is not retried. It does NOT change
// collection: that is enable() / disable()'s job, after consent.
function ensure(): Promise<boolean> {
  if (!ready) {
    ready = (async () => {
      try {
        const m = await import('./native/firebaseCrashlytics');
        plugin = m.FirebaseCrashlytics as unknown as Crashlytics;
      } catch {
        plugin = null; // unavailable — fail silent
      }
      return plugin !== null;
    })();
  }
  return ready;
}

function setCollection(on: boolean): void {
  if (!Capacitor.isNativePlatform() || collection === on) return;
  collection = on;
  void ensure().then((ok) => {
    if (!ok) return;
    plugin?.setEnabled({ enabled: on }).catch(() => {
      if (collection === on) collection = null; // not applied: let the next call retry
      // A fixed-string breadcrumb (which switch, never the error text), console only: Crash.log / recordError would go through the
      // same Crashlytics plugin whose setEnabled just failed. On Android the WebView console reaches logcat. Must never throw.
      try {
        console.warn(on ? 'crash: setEnabled on failed' : 'crash: setEnabled off failed');
      } catch {
        // no console: nothing more to do
      }
    });
  });
}

const keyType = (value: string | number): KeyType =>
  typeof value === 'string' ? 'string' : Number.isInteger(value) ? 'long' : 'double';

export const Crash = {
  init(): void {
    if (Capacitor.isNativePlatform()) void ensure();
    if (typeof window !== 'undefined') {
      window.addEventListener('error', (e: ErrorEvent) =>
        Crash.recordError(e.error ?? e.message, 'window.onerror'),
      );
      window.addEventListener('unhandledrejection', (e: PromiseRejectionEvent) =>
        Crash.recordError(e.reason, 'unhandledrejection'),
      );

  // state: a repeat of the same state makes no second native call. Never throws; a failed native call is forgotten so the next
  // call tries again (the value Crashlytics holds is then whatever an earlier launch persisted).
  enable(): void {
    setCollection(true);

  // when analytics_storage is denied. Sent even if enable() never ran this session, because an earlier launch may have persisted
  // "on". Same guarantees as enable(): single-flight per state, never throws.
  disable(): void {
    setCollection(false);
  },

  log(message: string): void {
    if (Capacitor.isNativePlatform()) {
      void ensure().then((ok) => {
        if (ok) plugin?.log({ message }).catch(() => {});
      });
    } else if (import.meta.env.DEV) console.debug('[crash:log]', message);
  },

  // rejected native call is forgotten so the next setKeys with that value tries again. Never throws.
  setKeys(keys: Readonly<Record<string, string | number>>): void {

    for (const [key, value] of Object.entries(keys)) {
      if (sentKeys.get(key) === value) continue;

  recordError(error: unknown, context?: string): void {
    const base = error instanceof Error ? error.message : String(error);
    const message = context ? `[${context}] ${base}` : base;
    // Dedupe, then the per-session cap (P00-T21): a repeat of a reported message, or anything past the cap, stops here.
    if (reported.has(message) || reported.size >= PLATFORM.CRASH_MAX_PER_SESSION) return;
    reported.add(message);
    if (Capacitor.isNativePlatform()) {
      const stacktrace = parseStack(error instanceof Error ? error.stack : undefined);
      const report = stacktrace.length > 0 ? { message, stacktrace } : { message };
      // .catch swallows any native failure so the global error bridge can't recurse.
      void ensure().then((ok) => {
        if (ok) plugin?.recordException(report).catch(() => {});
      });
    } else if (import.meta.env.DEV) console.error('[crash]', message, error);
  },
};
```

```ts
// Frame-loop error boundary (D-11, B-10, P00-T21). Phaser runs the game from one requestAnimationFrame callback, and that callback
// schedules the next frame only AFTER Game.step returns (node_modules/phaser/src/dom/RequestAnimationFrame.js, step). An exception
// anywhere inside a frame (input, a scene's update, a tween or timer callback, the render) therefore stopped the loop for good: the
// game froze and nothing told the player. installFrameGuard replaces game.step with a guarded step that never throws:
//   - every caught error is logged (console.error by default: logcat on Android, and the boot-smoke harness still sees it in the
//     production bundle, where Crash is silent on the web) and reported (deps.report: Crash.recordError in main.ts);
//   - an isolated error costs one frame and the loop goes on;
//   - FRAME_ERROR_BURST errors within FRAME_ERROR_WINDOW_MS (frameGuardDecision) mean the game cannot recover by itself: the loop is
//     put to sleep and deps.showOverlay() shows the "Tap to restart" overlay (errorOverlay.ts, plain DOM). The step then does nothing.
// Install it from the Game's READY event: Game.texturesReady emits READY and then calls start(), which binds this.step for the loop
// (node_modules/phaser/src/core/Game.js, texturesReady / start), so the guarded step is the one the loop calls.
// The game, the report and the overlay are passed in (no Phaser import, no services import): the guard is tested in node, and
// src/platform gains no dependency on src/services (src/platform/boundaries.test.ts).
import { PLATFORM } from '../config/platform.config';

export type FrameGuardDecision = 'continue' | 'overlay';

/** The part of Phaser.Game the guard touches. */
export interface GuardedGame {
  step(time: number, delta: number): void;
  readonly loop: { sleep(): void };
}

export interface FrameGuardDeps {
  /** Report one caught error (main.ts: Crash.recordError(error, 'frame')). */
  report(error: unknown): void;
  /** Show the restart overlay, once, after the loop has been put to sleep (main.ts: silence audio, then showErrorOverlay). */
  showOverlay(): void;
  /** Monotonic clock in ms. Default: performance.now(). */
  now?: () => number;
  /** Where each caught error is logged. Default: console.error. */
  log?: (message: string, error: unknown) => void;
}

export const FRAME_GUARD_LOG_PREFIX = '[frameGuard]';

/**
 * Pure. errorTimesMs: when the frame errors so far happened, the one just caught included. 'overlay' once FRAME_ERROR_BURST of them
 * fall within the last FRAME_ERROR_WINDOW_MS (an error exactly FRAME_ERROR_WINDOW_MS old no longer counts), else 'continue'.
 */
export function frameGuardDecision(errorTimesMs: readonly number[], nowMs: number): FrameGuardDecision {
  const recent = errorTimesMs.filter((t) => nowMs - t < PLATFORM.FRAME_ERROR_WINDOW_MS).length;
  return recent >= PLATFORM.FRAME_ERROR_BURST ? 'overlay' : 'continue';
}

const describeError = (error: unknown): string => (error instanceof Error ? `${error.name}: ${error.message}` : String(error));

// A dependency that throws must never escape the guard: that would stop the loop, the very thing the guard exists to prevent.
function quietly(fn: () => void): void {
  try {
    fn();
  } catch {
    // nothing more can be done from inside a failing frame
  }
}

const guarded = new WeakSet<GuardedGame>();

export function installFrameGuard(game: GuardedGame, deps: FrameGuardDeps): void {
  if (guarded.has(game)) return;
  guarded.add(game);
  const step = game.step; // Game.prototype.step, read before it is replaced
  const now = deps.now ?? (() => performance.now());
  const log = deps.log ?? ((message: string, error: unknown) => console.error(message, error));
  let errorTimes: number[] = [];
  let stopped = false;
  game.step = (time: number, delta: number): void => {
    if (stopped) return;
    try {
      step.call(game, time, delta);
    } catch (error) {
      const t = now();
      // Only the errors that can still count are kept, so a long session with rare errors keeps a short list.
      errorTimes = [...errorTimes.filter((x) => t - x < PLATFORM.FRAME_ERROR_WINDOW_MS), t];
      quietly(() => log(`${FRAME_GUARD_LOG_PREFIX} ${describeError(error)}`, error));
      quietly(() => deps.report(error));
      if (frameGuardDecision(errorTimes, t) === 'overlay') {
        stopped = true;
        quietly(() => game.loop.sleep());
        quietly(() => deps.showOverlay());
      }
    }
  };
}
```

```js
// P00-T21 (B-10): an exception inside a frame no longer freezes the game for good. window.__crashTest (src/main.ts, dev server only)
// makes the running scene's update throw, and the frame guard (src/platform/frameGuard.ts) must:
//   1. survive one throw: the error is logged, the game keeps stepping, no overlay;
//   2. after FRAME_ERROR_BURST throws within FRAME_ERROR_WINDOW_MS, put the loop to sleep and show the DOM overlay
//      "Something went wrong · Tap to restart" over the whole screen (src/platform/errorOverlay.ts);
//   3. on a tap anywhere, reload: the game boots back to the main menu, stepping, with no overlay.
// The injected errors are console.error lines by design: the guard logs every error it catches, and Crash logs its first report in
// the dev server (later identical ones are deduplicated). The check declares exactly those two lines with ctx.expectSignal right
// before it provokes them; any other error still fails the job.
//
// Dev mode only: the production bundle has no window.__crashTest (debug-handles proves it, at runtime and in dist/).

import { CRASH_TEST, DEV_HANDLES, ERROR_OVERLAY } from '../lib/copy.mjs';
import { bootToMenu, frames, isActive, waitFor } from '../lib/game.mjs';

// A failure limit and a progress count, both in page frames (never wall-clock sleeps).
const MAX_WAIT_FRAMES = 600;
const PROGRESS_FRAMES = 30;

/** Wait, frame by frame, until an expectation from ctx.expectSignal has seen at least n signals. */
async function waitForSignals(page, expectation, n, what) {
  for (let i = 0; i < MAX_WAIT_FRAMES && expectation.count() < n; i++) await frames(page, 1);
  if (expectation.count() < n) throw new Error(`waited ${MAX_WAIT_FRAMES} frames for ${what}: ${expectation.count()} of ${n} arrived`);
}

/** The game loop's frame counter and running flag, and whether the overlay is in the page. */
const loopState = (page) =>
  page.evaluate(
    (id) => ({ frame: window.__harnessGame.loop.frame, running: window.__harnessGame.loop.running, overlay: document.getElementById(id) !== null }),
    ERROR_OVERLAY.id,
  );

/** window.__crashTest(times), or window.__crashTest() when times is null. */
const crashTest = (page, times) => page.evaluate(([name, n]) => (n === null ? window[name]() : window[name](n)), [DEV_HANDLES.crashTest, times]);

export const crashOverlay = {
  name: 'crash-overlay',
  modes: ['dev'],
  weight: 25, // about seconds on a CI runner (it boots the game twice)
  async run(page, ctx) {
    const hook = await page.evaluate((name) => typeof window[name], DEV_HANDLES.crashTest);
    ctx.expect(hook === 'function', `the dev server defines window.${DEV_HANDLES.crashTest}()`, `typeof is ${hook}`);

    const guard = ctx.expectSignal({ kind: 'console.error', text: CRASH_TEST.guardLog }, 'the frame guard logs every injected frame error (console.error)');
    const reported = ctx.expectSignal({ kind: 'console.error', text: CRASH_TEST.crashLog }, 'the first injected frame error is reported to Crash (dev console.error)');

    // ---- 1. one transient throw ----
    await crashTest(page, 1);
    await waitForSignals(page, guard, 1, 'the single injected frame error');
    const before = await loopState(page);
    await frames(page, PROGRESS_FRAMES);
    const after = await loopState(page);
    ctx.expect(after.running && after.frame > before.frame && !after.overlay, 'one frame error: the game keeps stepping and no overlay appears', JSON.stringify({ before, after }));
    ctx.expect(await isActive(page, 'MainMenuScene'), 'one frame error: the main menu is still running');

    // ---- 2. a persistent error ----
    await crashTest(page, null);
    await waitFor(page, 'the error overlay', (id) => document.getElementById(id) !== null, ERROR_OVERLAY.id);
    await waitForSignals(page, guard, CRASH_TEST.burst, `${CRASH_TEST.burst} logged frame errors`);
    ctx.expect(guard.count() >= CRASH_TEST.burst, `the overlay came after at least ${CRASH_TEST.burst} frame errors`, `${guard.count()} logged`);
    const overlay = await page.evaluate(
      ([id, x, y]) => {
        const el = document.getElementById(id);
        const top = document.elementFromPoint(x, y);
        return {
          text: el ? el.textContent : '',
          role: el ? el.getAttribute('role') : null,
          count: document.querySelectorAll(`#${id}`).length,
          covers: !!top && top.closest(`#${id}`) !== null,
        };
      },
      [ERROR_OVERLAY.id, ctx.viewport.width / 2, ctx.viewport.height / 2],
    );
    ctx.expect(overlay.text.includes(ERROR_OVERLAY.title) && overlay.text.includes(ERROR_OVERLAY.action), `the overlay reads "${ERROR_OVERLAY.title}" and "${ERROR_OVERLAY.action}"`, overlay.text);
    ctx.expect(overlay.count === 1 && overlay.role === 'alertdialog', 'exactly one overlay, announced as an alert dialog', JSON.stringify(overlay));
    ctx.expect(overlay.covers, 'the overlay is on top of the game at the centre of the screen');
    const asleep = await loopState(page);
    await frames(page, PROGRESS_FRAMES);
    const still = await loopState(page);
    ctx.expect(!asleep.running && still.frame === asleep.frame, 'the game loop is asleep: no frame runs under the overlay', JSON.stringify({ asleep, still }));

    // ---- 3. tap to restart ----
    const reloaded = page.waitForEvent('load');
    await page.mouse.click(ctx.viewport.width / 2, ctx.viewport.height / 2);
    await reloaded;
    await bootToMenu(page);
    const fresh = await loopState(page);
    await frames(page, PROGRESS_FRAMES);
    const later = await loopState(page);
    ctx.expect(!fresh.overlay && later.running && later.frame > fresh.frame, 'a tap reloads the page: the game boots back to the main menu, stepping, with no overlay', JSON.stringify({ fresh, later }));
    ctx.expect(reported.count() === 1, 'Crash reported the injected error once: the repeats of the same message were deduplicated', `${reported.count()} reports`);
  },
};
```

```js
import { readdirSync, readFileSync } from 'node:fs';
import path from 'node:path';

const harnessOwned = (key) => key.startsWith('__harness');
const NAMES = Object.values(DEV_HANDLES);

/** Every .js file under dir, recursively. */
function jsFiles(dir) {
  return readdirSync(dir, { withFileTypes: true }).flatMap((entry) => {
    const full = path.join(dir, entry.name);
    if (entry.isDirectory()) return jsFiles(full);
    return entry.name.endsWith('.js') ? [full] : [];

}
```
